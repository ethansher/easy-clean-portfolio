Pill-shaped uppercase action button for interactive surfaces.

```jsx
<Button variant="primary">Next page</Button>
<Button variant="cool" size="sm">Filter</Button>
<Button variant="ghost">Back</Button>
```

Variants: `primary` (orange), `cool` (electric blue), `ghost` (outline, for use on blue), `quiet` (grey). Sizes `sm|md|lg`. Scales down on press.
